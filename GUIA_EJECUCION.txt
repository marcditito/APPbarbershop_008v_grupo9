                    ⚠️ SOLUCION DE PROBLEMAS COMUNES
═══════════════════════════════════════════════════════════════════════════════

PROBLEMA 1: "App keeps stopping" al abrir
──────────────────────────────────────────
SOLUCION:
   • Abre Android Studio
   • Ve a: Run > Edit Configurations
   • En "Launch Options", cambia "Launch" a "Nothing"
   • Aplica y vuelve a ejecutar
   • Luego abre la app manualmente desde el dispositivo

PROBLEMA 2: Permisos denegados
───────────────────────────────
SOLUCION:
   • La app pedirá permisos al abrirse
   • Acepta todos los permisos:
     ✓ Cámara
     ✓ Ubicación
     ✓ Archivos/Fotos
   • Si los rechazaste, ve a Settings > Apps > Barber Shop > Permissions
   • Activa todos los permisos

PROBLEMA 3: No compila
───────────────────────
SOLUCION:
   • Ejecuta REBUILD_COMPLETE.bat nuevamente
   • Si persiste, ejecuta clean_build.bat
   • Como último recurso, ejecuta clean_global_gradle.bat

PROBLEMA 4: Gradle sync failed
───────────────────────────────
SOLUCION:
   • File > Invalidate Caches / Restart
   • Elige "Invalidate and Restart"
   • Espera y vuelve a sincronizar

PROBLEMA 5: Device offline / not found
───────────────────────────────────────
SOLUCION:
   • Si es dispositivo físico:
     - Desconecta y reconecta el USB
     - Acepta "Allow USB Debugging" en el dispositivo
     - Verifica que esté en modo "File Transfer"

   • Si es emulador:
     - Cierra el emulador
     - Ábrelo de nuevo desde AVD Manager
     - Espera a que arranque completamente

PRUEBA 1: Añadir un producto

──────────────────────

────────────────────────────

   3. Haz clic en el FAB del carrito
   4. El producto aparece en el carrito
   5. Se muestra el total

PRUEBA 4: Eliminar del carrito
───────────────────────────────
   1. Abre el carrito
   2. Haz clic en el icono de basura (🗑️) de un producto
