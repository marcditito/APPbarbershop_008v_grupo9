📝 PARA DESARROLLADORES
─────────────────────────────────────────────────────────────────────

El login está implementado en:
📄 LoginActivity.kt
📄 LoginViewModel.kt
📄 activity_login.xml

Las credenciales están hardcodeadas en LoginViewModel.kt:
```kotlin
if (email == "demo@barbershop.com" && password == "123456") {
    _loginState.value = LoginState.Success("Bienvenido")
} else {
    _loginState.value = LoginState.Error("Credenciales inválidas")
}
```

🔧 SOLUCIÓN DE PROBLEMAS
─────────────────────────────────────────────────────────────────────

PROBLEMA: No puedo iniciar sesión
SOLUCIÓN:
• Verifica que el email sea exactamente: demo@barbershop.com
• Verifica que la contraseña sea exactamente: 123456
• No agregues espacios antes o después

PROBLEMA: La app no abre la pantalla de login
SOLUCIÓN:
• Asegúrate de haber compilado correctamente
• Verifica que LoginActivity esté en el AndroidManifest.xml
• Revisa los logs de Android Studio

PROBLEMA: El botón biométrico no aparece
SOLUCIÓN:
• Es normal, está oculto por defecto en el código
• Para habilitarlo, edita LoginActivity.kt:
  Comenta estas líneas:
  // binding.buttonBiometric.visibility = View.GONE
  // binding.dividerLayout.visibility = View.GONE
