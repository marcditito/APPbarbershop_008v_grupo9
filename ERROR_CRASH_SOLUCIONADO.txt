🐛 PROBLEMA IDENTIFICADO
═══════════════════════════════════════════════════════════════════════

La app se cerraba después de iniciar sesión porque:

❌ MainActivity solicitaba permisos que NO EXISTEN en AndroidManifest:
   - Manifest.permission.ACCESS_FINE_LOCATION
   - Manifest.permission.ACCESS_COARSE_LOCATION

Código problemático en MainActivity.kt (líneas 45-60):
```kotlin
private val permissions = mutableListOf(
    Manifest.permission.CAMERA,
    Manifest.permission.ACCESS_FINE_LOCATION,    // ❌ NO declarado
    Manifest.permission.ACCESS_COARSE_LOCATION   // ❌ NO declarado
).apply {
    // ...
}
```

Cuando la app intentaba solicitar estos permisos no declarados → CRASH

═══════════════════════════════════════════════════════════════════════

✅ SOLUCIÓN APLICADA
─────────────────────────────────────────────────────────────────────

1. ELIMINADO todo el código de solicitud de permisos en MainActivity
   Razón: Los permisos solo deben solicitarse cuando se necesitan
         (en AddProductActivity al tomar foto)

2. SIMPLIFICADO onCreate() en MainActivity:
   Antes:
   ```kotlin
   override fun onCreate(savedInstanceState: Bundle?) {
       super.onCreate(savedInstanceState)
       binding = ActivityMainBinding.inflate(layoutInflater)
       setContentView(binding.root)
       checkAndRequestPermissions() // ❌ Causaba crash
   }
   ```

   Ahora:
   ```kotlin
   override fun onCreate(savedInstanceState: Bundle?) {
       super.onCreate(savedInstanceState)
       binding = ActivityMainBinding.inflate(layoutInflater)
       setContentView(binding.root)
       setupUI() // ✅ Directo, sin permisos
   }
   ```

3. ELIMINADOS métodos innecesarios:
   - checkAndRequestPermissions()
   - requestPermissionLauncher
   - Array de permissions

4. LIMPIADOS imports innecesarios:
   - android.Manifest
   - android.content.pm.PackageManager
   - android.os.Build
   - androidx.core.content.ContextCompat

💡 NOTA TÉCNICA
─────────────────────────────────────────────────────────────────────

Mejores prácticas Android:
✓ Solicitar permisos SOLO cuando se necesitan
✓ NO solicitar permisos en onCreate() de actividad principal
✓ Solicitar en el momento de uso (al hacer click en cámara)
✓ Nunca solicitar permisos no declarados en Manifest

Esto es exactamente lo que hemos implementado:
- MainActivity: Sin permisos (no los necesita)
- AddProductActivity: Solicita permisos al usar cámara/galería
