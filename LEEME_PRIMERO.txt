✨ CAMBIO TÉCNICO EXPLICADO:

  La opción -XX:MaxPermSize controlaba la memoria PermGen en Java 6-7.
  En Java 8+ (incluido Java 17), PermGen fue eliminado y reemplazado
  por Metaspace, que no tiene límite separado.

  Por eso, simplemente quitar la opción es la solución correcta.

  Tu configuración ahora es:
  ✓ Compatible con Java 17
  ✓ Compatible con Gradle 8.13
  ✓ Optimizada y moderna
