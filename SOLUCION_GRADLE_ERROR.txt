SOLUCION COMPLETA - ERROR GRADLE DAEMON
========================================

PROBLEMA:
El error "Unrecognized VM option 'MaxPermSize=1024m'" ocurre porque esa opción
es obsoleta en Java 17 y no se acepta en versiones modernas de Java.

SOLUCION APLICADA:
==================

1. ✅ MODIFICADO: gradle.properties
   - Se eliminó: -XX:MaxPermSize=1024m
   - Quedó: org.gradle.jvmargs=-Xmx4096m
   Ubicación: C:\Users\duran\OneDrive\Escritorio\BarberShopApp\BarberShopApp\gradle.properties

2. ✅ CREADO: fix_gradle.bat
   Script automático para limpiar todo y reconstruir.
   Ubicación: C:\Users\duran\OneDrive\Escritorio\BarberShopApp\BarberShopApp\fix_gradle.bat

QUE HACER SI PERSISTEN LOS ERRORES:
====================================

Si después de seguir los pasos anteriores aún ves errores de Kotlin:

1. En Android Studio, ve a: File > Project Structure
2. En "Project", verifica que la versión de Kotlin sea 1.9.x o compatible
3. Si dice 2.1.x pero tienes 1.9.x instalado, hay mismatch de versiones

Para sincronizar versiones (en build.gradle raíz):
   buildscript {
       dependencies {
           classpath "org.jetbrains.kotlin:kotlin-gradle-plugin:1.9.22"
       }
   }

O si quieres usar Kotlin 2.1.20, todos los plugins deben ser 2.1.20

VERIFICACION:
=============

Debe mostrar una versión compatible sin errores de MaxPermSize.
